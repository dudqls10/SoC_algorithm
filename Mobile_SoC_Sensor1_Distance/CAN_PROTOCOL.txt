모바일 ASIC / SoC 공통 CAN 출력 (2026-10-01)

표준 CAN, 1 Mbps, DLC=8. 현재 센서 버전의 송신 ID는 0x41~0x44 네 종류뿐입니다.
각 데이터 프레임은 32비트 값 두 개이며 바이트 순서는 Big Endian입니다.

ID     Byte 0~3                              Byte 4~7
0x41   원시 CH0 count (uint32, 최초 수신)    원시 CH1 count (uint32, 최초 수신)
0x42   dComps.fdc_Q1 (drift 보상 + EMA 후)    cvf.FilteredDistance_Q1 (int32, mm)
0x43   fusion.FusedDistance_Q1 (int32, mm)    tof.distance[0] (uint32, mm)
0x44   아래 상태 바이트 8개

0x44:
B0 상태 비트: bit0 칩 초기화 OK, bit1 CH0 알고리즘 샘플 유효, bit2 CH1 알고리즘 샘플 유효,
              bit3 ToF 초기화 OK, bit4 최근 정상 ToF 거리 읽기,
              bit5 fusion 유효, bit6 EMA 초기화 완료, bit7 센싱 ON.
B1 라인/SoC 진단 비트: bit0 I2C1 SCL, bit1 I2C1 SDA, bit2 I2C3 SCL, bit3 I2C3 SDA,
              bit4 I2C1 BUSY, bit5 I2C3 BUSY. 하위 6비트가 0x0F이면 모두 HIGH, BUSY=0.
              SoC 평가 펌웨어(2026-10-06): bit6 장애물 판정(1=학습 정지),
              bit7 실제 보상 학습 갱신 횟수의 홀짝 비트(갱신마다 토글).
              bit6/7은 이동 중 SWD 없이 판정과 학습 진행을 관찰하기 위한 진단이며,
              0x41~0x43의 값과 필터/보상/학습 파라미터는 변경하지 않습니다.
B2 bit1:0 칩 초기화 HAL 상태, bit3:2 CH0 읽기 HAL 상태,
   bit5:4 CH1 읽기 HAL 상태, bit7:6 칩 종류 (1=ASIC, 2=SoC).
   HAL: 0=OK, 1=ERROR, 2=BUSY, 3=TIMEOUT. 정상 ASIC=0x40, 정상 SoC=0x80.
B3 0x41 원시 count 수신 시점의 CH0/CH1 overflow/error 비트.
   bit0 CH0 overflow, bit1 CH1 overflow, bit4 CH0 error, bit5 CH1 error.
   ASIC STATUS 또는 SoC 데이터 레지스터 상위 플래그를 이 비트로 매핑합니다.
B4 마지막 ToF API 상태 (int8, 0=OK, 음수=실패; 기동 미완료=-7).
B5 CAN 송신 큐 등록 실패/대기 횟수의 하위 8비트.
B6 양 채널 I2C 읽기 성공 횟수의 하위 8비트.
B7 정상 ToF 거리 업데이트 횟수의 하위 8비트.

카운터는 256마다 순환합니다. B5는 CAN 배선 오류의 확정 판정값이 아닙니다.
0x41은 칩 데이터 레지스터에서 처음 읽은 하위 24비트 count를 32비트로 전송합니다.
Kalman, drift, EMA, slew limiter 및 ASIC 포화 복구 재읽기 결과로 대체하지 않습니다.
칩 overflow/error나 알고리즘 샘플 거부가 있어도 수신한 원시 count를 표시합니다.
I2C 읽기 실패 시 해당 채널의 마지막 수신 count와 B3 플래그를 유지합니다.
전원 기동 후 한 번도 읽지 못한 채널은 0입니다. 읽기 실패는 B2, 칩 오류는 B3로 확인하세요.
B0의 CH0/CH1 유효 비트는 알고리즘에 채택된 샘플을 뜻하며 원시 데이터와 다를 수 있습니다.
0x42/0x43은 마지막 계산 값을 전송하며, 알고리즘 유효성은 B0로 판단합니다.
내부 fdc.ch300/ch302와 거리 계산은 기존 Kalman 및 보상 경로를 유지합니다.
네 프레임은 첫 프레임 때 같은 시점으로 저장한 값으로 구성합니다.
한 CAN 타이머 주기마다 한 프레임씩 전송합니다. 센서 읽기 주기는 변경하지 않았습니다.
라인 상태는 저장 시점의 GPIO 값이며 통신 파형 전체를 판정하지 않습니다.
ASIC의 ToF 최신성 기준은 120 ms 및 기존 range-status 검증입니다.
SoC의 ToF 최신성 기준은 정상 거리 읽기 후 200 ms입니다.
학습 보호는 추가로 광학 range-status=0인 새 측정값만 사용합니다.
이 품질 조건은 기존 거리 출력과 B0 ToF 비트의 의미를 바꾸지 않습니다.
학습은 장애물 판정 외에도 정상 모델 잔차·ToF 접근·최신성을 확인합니다.
새 학습 표본은 최소 2.4초 대기하고, 학습 보류 시 대기 표본을 폐기합니다.
B1 bit7은 대기 표본 수가 아니라 실제 학습 모델 반영 횟수의 홀짝입니다.
학습 보류 사유와 실제 학습에 반영한 CH0/CH1은 내부 진단 기록에 저장합니다.

기존 0x45~0x4D의 raw/추가 채널/레지스터 페이지/기동/통계/이벤트 진단 송신은 제거했습니다.
ToF I2C1(PB6/PB7), 칩 I2C3(PA8/PC9), 두 버스 400 kHz 설정을 유지합니다.
