## 모바일 통신 구성

- ToF는 I2C1(PB6 SCL / PB7 SDA), 칩은 I2C3(PA8 SCL / PC9 SDA)를 사용합니다.
- 두 버스는 400 kHz Fast mode이며 `.ioc`와 생성 C 설정을 함께 유지하세요.
- ToF 데이터는 논리 슬롯 0을 사용합니다. XSHUT은 외부 풀업이며 MCU 제어선은 없습니다.
- 공유 버스용 단계 기동 시험을 모바일 프로젝트에 다시 적용하지 마세요.

## CAN 출력

- 모바일 ASIC과 SoC는 `CAN_PROTOCOL.txt`의 같은 0x41~0x44 구성을 사용합니다.
- 0x41은 최초 수신 원시 CH0/CH1 count이며, 필터 및 포화 복구 재읽기 값으로 대체하지 마세요.
- 0x42/0x43은 EMA 이후 dComps.fdc_Q1, CVF 거리, fusion 거리, ToF 거리이며 0x44는 최소 상태입니다.
- 요청 없이 예전 0x45~0x4D 진단 프레임을 다시 추가하지 마세요.
